# S05 Super Tetsudo POS 终端故障报告

报告人：S05 店长 高远
报告日期：2026-08-04
抄送：总部运营部、IT 部、财务部

## 一、经过

**2026-08-03 10:40 起**，Super Tetsudo（S05，上海·黄浦）的刷卡与扫码支付终端全部无法连到支付网关，刷卡、微信、支付宝、会员储值都提示网络异常，收银机本身能正常开单打单。
故障是开店前例行检查收银设备时发现的，当时离 11:00 开门还有二十分钟。10:45 上报商场物业和总部 IT 部，11:00 前后确认原因：**商场当天进行网络交换机升级**，商户专线在切换过程中中断，同层受影响的商户不止我们一家。
门店 **11:00 按时开门，当天从开门到打烊全程只收现金**，收银台和门口各贴一张告知，排队的顾客提前口头告知，附近有取现网点的位置也一并告知。
物业于 **2026-08-04 07:30** 完成割接回退并恢复专线，开店前 IT 部远程测试，刷卡、扫码、会员储值全部正常，当日恢复正常收款。

## 二、影响

1. **2026-08-03 当天 S05 的订单全部以现金结算**，POS 里的 `payment` 一律记为“现金”。
2. 有一部分只带手机出门的顾客当场放弃下单，午市和晚市都有流失，具体少了多少以系统数据为准，本报告不估算。
3. 收银现金与系统日报核对一致，无金额差错，无投诉升级。

## 三、改进

1. 门店常备零钱由 500 元提高到 1,500 元，由店长每周一核对。
2. 增加一台 4G 移动收款终端作为备份，由 IT 部在 8 月内配置到位，每月月初测试一次。
3. 商场再有网络升级，要求物业提前 3 个工作日书面通知门店，运营部已与物业沟通并写进沟通纪要。
4. 只收现金的告知模板由市场部统一做好存档，门店随时可打印。
