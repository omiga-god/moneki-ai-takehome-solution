# 知识库目录说明

维护部门：总部运营部（知识管理岗）

本目录存放五家门店日常运营要用的制度、通知与参考资料。
本文件只是目录说明，不是知识库文档：它不编号、不列入文档清单，引用来源时也不算一份资料。

## 一、各子目录放什么

- `handbook/`：指标口径手册。报表和对外数字的算法以这里为准。
- `policies/`：总部制度。会员储值、退款、员工餐与折扣、食品安全、排班考勤都在这里。
- `notices/`：一次性的通知与报告，包括停业、停售、调价、活动方案、故障报告和例会纪要。
- `stores/`：门店档案，一店一份。
- `reports/`：店长周报，按门店和周次归档。
- `reference/`：对照表与汇总类资料，例如过敏原、供应商、营业时间总表、顾客反馈和对外常见问题页面。
- `legacy/`：从旧系统导出的历史文件，保持原样，不重排、不改写。

## 二、命名与格式

1. 文件名一律写成 `KB-xxx_标题.扩展名`。编号由运营部统一分配，分配之后不改动、不复用。
2. `.md` 文件带一段 YAML 头，写明编号、标题、类型、状态、生效日期和更新日期；只涉及个别门店的写明适用门店，被新版取代的写明取代它的编号。
3. `.txt` 与 `.html` 是从旧系统或官网原样保留的，没有 YAML 头，这类信息只出现在正文里，要自己从正文里找。
4. 制度换版不删旧版：旧版留在原位，状态改为 `已废止`，并写明现行版本是哪一份；要查“当时有效”的规定，看各版本的生效日期。

## 三、新增与修改

需要新增或修改文档的，把草稿发给运营部知识管理岗徐敏（内线 8117），由运营部编号、归档并通知各店。
门店不要自己往目录里放文件，也不要用店群截图代替归档。
