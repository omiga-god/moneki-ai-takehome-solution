# 指标口径手册 v2

> 本版本已废止，现行版本见 KB-001。

适用范围：总部运营部、财务部，以及各门店的月度经营报表。
本手册自 2025-09-01 起生效。

## 1. 规范化

1. `store_id`、`product_id`：去掉首尾空白并转为大写。
2. `date`：接受 `YYYY-MM-DD`、`YYYY/M/D`、`DD-MM-YYYY` 三种格式。
3. `amount`：去掉 `¥` 前缀与首尾空白之后按数字解析。
4. `qty`：按整数解析。

## 2. 剔除

按下列顺序执行：

1. 日期无法解析的行。
2. `qty ≤ 0` 的行。
3. 规范化后 `store_id` 不在 `stores` 表里的行。
4. 规范化后 `product_id` 不在 `products` 表里的行。
5. 规范化后所有字段完全相同的重复行，只保留 1 条。
6. `amount` 小于 0 的退款行。退款不计入营业额，在清洗阶段直接剔除；退款金额由财务在退款台账里单独统计，不进经营报表。

## 3. 缺失金额的处理

`amount` 为空的行不剔除，按 `qty × unit_price` 回填，其中 `unit_price` 取 `products` 表的建档价。
回填之后的行参与全部统计，不另做标记。
门店发现某天缺失金额的行特别多时，报 IT 部检查 POS 导出任务，但已经回填的报表不重跑。

## 4. 指标定义

- **营业额** = 全部销售行金额之和。
- **明细行数** = 通过剔除规则后剩下的行数。
- **客单价** = 营业额 ÷ 明细行数，四舍五入保留 2 位小数。
- **销量** = 销售行 `qty` 之和。
- 按日期、门店、商品筛选时，以明细行上的日期、门店、商品为准。

## 5. 数字来源

经营数字以数据库计算结果为准。
门店自行统计的数字、手工台账、活动现场清点的数字都只能当参考，不作为报表依据。
商品售价以调价通知为准，`products` 表的建档价由财务在月底统一更新。

## 6. 报送要求

各门店月报于次月 3 日前提交总部运营部，财务部于次月 5 日前完成复核。
口径有疑问的先问运营部，不要自行调整算法。
