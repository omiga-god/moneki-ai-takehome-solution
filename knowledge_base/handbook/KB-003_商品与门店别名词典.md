# 商品与门店别名词典

店长口头汇报、顾客留言、外卖平台后台、供应商邮件里，对同一样东西经常有好几种叫法，查数和写报表的时候很容易对不上。
下面两张表把常见叫法统一到数据库里的标准写法。检索、统计、出报表时一律以“数据库写法”这一列为准，其余写法视为同一个对象的别名。

## 一、商品

| 数据库写法 | 常见别名 | 说明 |
|---|---|---|
| 味增拉面 | 味噌拉面、Miso Ramen | 数据库里的写法是“味增拉面”，这是早年录入时留下的写法。菜单、物料、外卖平台上印的都是“味噌拉面”，两者是同一个商品，从来没有改过名，查数时两种写法都要命中 |
| 豚骨拉面 | Tonkotsu Ramen、白汤拉面 | |
| 牛肉poke | 牛肉波奇饭、Beef Poke | 顾客口头也常说“牛肉饭”，但这和照烧鸡饭不是一回事，接待时要问清楚 |
| 三文鱼poke | 鲑鱼波奇饭、Salmon Poke | 供应商邮件里一律写 Salmon，原料单上写“鲑鱼” |
| 鸡肉poke | Chicken Poke | |
| 吞拿鱼三明治 | 金枪鱼三明治、Tuna Sando | |
| 照烧三明治 | 照烧鸡三明治、Teriyaki Sando | |
| 小笼包 | XLB、汤包 | 和灌汤包是两个商品，不要混 |
| 灌汤包 | 蟹粉灌汤包 | |
| 冷萃乌龙茶 | 冷萃乌龙、Cold Brew Oolong | 2026 年 8 月上市的新品 |
| 抹茶拿铁 | Matcha Latte | |
| 毛豆 | 盐水毛豆、Edamame | |

## 二、门店

| 数据库写法 | 门店编号 | 常见别名 |
|---|---|---|
| Super Souper | S01 | SS、汤面店 |
| Makai Poke | S02 | Makai |
| Juicy Bao Bao | S03 | JBB、包包店 |
| Arigato Sando | S04 | 阿里嘎多、AS |
| Super Tetsudo | S05 | 铁道、ST |

## 三、使用说明

1. 别名只用于检索和理解，不改数据库里的原始值，也不做批量改名。
2. 跨语言的材料（例如英文供应商邮件）先按本表把英文名映射回数据库写法，再去查数。
3. 新增商品或门店改名，由运营部在本表登记后再对外使用，不要各部门各叫各的。
4. 本表不涉及价格、规格、过敏原，相关内容分别见调价通知与过敏原对照表。
